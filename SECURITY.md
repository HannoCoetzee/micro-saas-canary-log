# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in CanaryLog, please report it responsibly.

- **Email**: hello@uncomfortablebudget.com
- **Do NOT** open a public GitHub issue for security vulnerabilities.

We will acknowledge receipt within 48 hours and provide a timeline for a fix.

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |

## Disclosure Policy

- We follow responsible disclosure.
- Security issues will be fixed and disclosed after a patch is released.
